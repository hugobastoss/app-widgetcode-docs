1. What the app is

WidgetCode is a study and reference tool for people who build with Flutter. It gathers examples of Flutter's native widgets, organized by section, that run in the app itself and show each one's source code. The app also copies ready-made requests so you can bring an example into your project with the help of a coding AI.

Important: the examples are for teaching. They show how each widget is used in a simplified way, with demo data and texts, and are not production-ready components. Review, test and adapt the code before using it in a real app.
